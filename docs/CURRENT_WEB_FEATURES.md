# 현재 웹 기능과 기록 — 2026-10-02

주요 메뉴는 오늘 요약, AI 보행동결, 발 움직임, 정면 보행, 압력·온습도입니다. 연결과 개인 AI 보정은 기기 설정에서, 저장 자료는 데이터관리에서 확인합니다.

## 데이터관리

| 탭 | 실제 자료 | 저장 위치·표시 범위 |
|---|---|---|
| FOG 분석 자료 | CSV 도구로 수집한 BMI 보정·측정 파일과 모델 분석 결과 | PC AI 서버의 자료 목록. 실시간 점수 전체가 자동 저장되는 목록은 아님 |
| 발 움직임 기록 | BMI 발 기울기의 기준 이탈 시각·최대값·센서 X/Y 축 | PC에 저장된 이벤트 중 오늘 기록. 기준은 현재 서버의 오늘 기준 |
| 정면 보행 기록 | 2초 기준 준비 + 10초 관찰. 유효 인식률·기준 변화 지속 시간·골반선/몸통 최대 변화각 | 해당 브라우저, 최근 20건 / 최대 30일. 기존 20초 기록 유지. 영상·각도 시계열은 저장하지 않음 |
| 압력·온습도 기록 | 센서 표본의 날짜별 요약과 같은 조건 비교 | PC 30일. 저장 동의 후 기록 시작. 탭/메뉴 이동 시 종료 |

예전 MediaPipe의 정면·좌측·우측 관절 측정과 3방향 세트는 현재 정면 보행과 다른 기능입니다. 데이터관리 아래 접힌 **이전 버전의 관절 기록 보관함**에서 기존 `/api/rom` 자료를 읽고 전체 JSON으로 내려받을 수 있습니다. 기존 저장 파일이나 API는 삭제하지 않았습니다.

압력·온습도 기록 탭은 이전 관절 저장 API에 의존하지 않습니다. 센서 표본 저장 중 다른 종류로 전환하면 기존 저장 종료 확인을 거치고, 마지막 표본을 저장 중이면 이동을 보류합니다. 비동기 응답은 선택한 탭이 그대로일 때만 적용합니다.

기존 `view=trends` 링크는 데이터관리의 센서 기록으로, `view=reports`는 데이터관리로 연결됩니다. 압력 상세 링크는 압력·온습도 메뉴로 연결됩니다.

## 표시 범위

FOG는 학습된 AI와 현재 보조 판단 결과입니다. BMI 발 기울기는 정강이와 발 사이의 실제 발목 관절 ROM이나 부상 위험이 아닙니다. 정면 카메라는 골반선과 몸통의 영상상 변화만 관찰합니다. 압력·온습도는 상대 압력과 센서 위치의 환경값입니다.

실제 센서값이 없을 때 결과를 만들어 채우지 않습니다. 이번 UI 정리에서 모델·개인 보정값·센서 펌웨어·저장 자료는 변경하지 않았습니다.
