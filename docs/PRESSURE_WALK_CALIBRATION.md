# 정상 보행 최고값으로 압력 표시

기기 설정 → 개인 기준 설정 → 왼발/오른발 **BMI·압력 보정**을 각각 실행합니다.
3초 준비, 5초 정지 후 **20초 정상 보행 구간**에서만 각 압력센서의 최대 원시 ADC를 수집합니다.
추가 보정 시간은 없습니다. 이전 BMI 보정 파일에는 이 기준이 없으므로 한 번 다시 보정해야 합니다.

- 표시값 = 현재 ADC / 해당 센서의 보행 최대 ADC × 100. 표시 범위는 0~100%.
- 최대값 초과 여부는 `pressure_calibration.over_max`에, 원시 ADC는 `pressure_raw`에 유지합니다.
- 양발 기준은 따로 저장합니다. 2센서는 `[0,0,1,1]`로 두 물리 센서만 보정하고 짝 표시는 같은 값입니다. 4센서는 각각 보정합니다.
- 유효 표본 20개 이상, 시간 범위 10초 이상, 모든 물리 센서 최대 ADC 32 이상이 있어야 적용합니다. 무응답/0/작은 잡음을 100%로 확대하지 않습니다.
- 실패·취소된 BMI 보정은 기존 저장 파일을 바꾸지 않습니다. 성공했지만 압력 수집이 부족하면 압력 기준은 미완료이며 기본 ADC 비율과 재보정 안내를 표시합니다.
- 기기 ID·발·센서 구성·채널 배치가 다르면 적용하지 않습니다. 센서 위치나 착용자가 바뀌면 직접 재보정해야 합니다.

`web/ai_bridge/server.py`가 기존 `.stepon-data/ai/{left,right}.calibration.json`의
`pressure_normalization`에 기준을 함께 저장합니다. 웹 서버는 1초마다 다시 읽으므로 보정 뒤 새로고침이나 재시작이 필요 없습니다.
사용자 지정 저장 폴더는 두 서비스에 같은 `STEPON_AI_DATA_DIR`을 지정합니다.

허브의 화면용 스냅샷, 히트맵, 압력 중심과 관찰 피드백, 새 센서 요약 기록에는 보정 비율을 사용합니다.
원시 프레임 이력(`/api/insoles/samples`의 `samples`)과 RF/CNN·압력 FOG 보조 규칙의 입력은 변환하지 않습니다.
기록의 비교 조건에는 양발 압력 보정 ID를 넣어 이전 기준과 합치지 않습니다.
기존 기록을 소급 변환하지 않습니다. 최대 ADC를 기준으로 한 상대값이며 실제 힘/체중 비율 측정은 아닙니다.
