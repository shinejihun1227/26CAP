# 서 있을 때 50점으로 압력 표시

기기 설정 → 개인 기준 설정 → 왼발/오른발 **BMI·압력 보정**을 각각 실행합니다.
3초 준비 후 양발을 편히 딛고 **처음 5초 동안 서 있는 값**을 저장하고, 이후 20초는 기존 BMI 보행 보정을 진행합니다.
이전의 보행 최고값 90점 방식은 사용하지 않습니다. 이전 보정 파일은 유지하지만 서 있는 기준으로 다시 보정하기 전까지 기본 ADC 비율과 재보정 안내를 표시합니다.

- 표시값 = 현재 ADC ÷ 해당 센서의 서 있는 기준 ADC × 50. 화면은 0~100점으로 제한합니다.
- 예: 서 있을 때 ADC가 1000이면 현재 500 → 25점, 1000 → 50점, 1500 → 75점, 2000 이상 → 100점입니다.
- 기준은 처음 5초의 유효 정지 표본 중앙값입니다. 움직이거나 걷는 동안 갱신하지 않습니다.
- BMI의 중력 크기 오차가 0.12g 이내이고 자이로 벡터 크기가 12°/s 이하인 표본을 사용합니다. 유효 표본 20개 이상, 시간 범위 3초 이상, 모든 센서 기준 ADC 32 이상이 필요합니다.
- 발당 2센서는 `[0,0,1,1]`로 공유하며 짝 표시는 동일합니다. 4센서는 각각 독립 기준을 저장합니다. 미연결·0·작은 잡음을 50점으로 확대하지 않습니다.
- 실패하거나 취소한 BMI 보정은 기존 파일을 바꾸지 않습니다. BMI 보정은 성공했지만 압력 수집이 부족하면 압력은 미완료로 표시합니다.
- 기기 ID·발·센서 구성·채널·직접 입력 핀이 달라지면 다시 보정해야 합니다.

`.stepon-data/ai/{left,right}.calibration.json`의 `pressure_normalization`에 버전 2, 방식 `standing-50-v1`, `reference_raw`를 저장합니다. 웹 서버는 1초마다 파일을 다시 읽습니다.
화면 메타데이터에는 `reference_score:50`, `over_reference`, 제한 전 `unclipped_score`, 원본 `source_id`를 포함합니다.

히트맵, 앞뒤 상대 중심, 관찰 피드백에는 같은 보정값을 사용합니다. RF/CNN과 압력 FOG 보조 규칙의 원시 입력은 바꾸지 않습니다.
비교 기록에는 별도의 기준 ID를 사용해 이전 90/100점 방식과 섞지 않습니다. 기존 기록은 소급 변경하지 않습니다.
이 값은 센서별 평소 서 있는 압력 대비 상대 점수이며 힘·체중 비율이나 부상 위험도는 아닙니다.
