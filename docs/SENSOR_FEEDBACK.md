# 센서 기록과 Ollama 보행 안내 (2026-10-02)

## 어떤 기록을 쓰나

오늘의 최근 관찰 기록을 발별로 사용한다. 버튼을 누르면 먼저 서버의 최신 기록을 읽고 그 기록 ID로 Ollama에 요청한다. 원본 영상·사용자 이름·기기 ID는 전달하지 않는다.

| 구분 | 기록 조건 | Ollama에 전달하는 정보 |
| --- | --- | --- |
| 발 기울기 | 개인 기준의 최대 기울기 + 5°를 새 프레임 3개 이상, 1초 이상 초과 | 발, 센서 X/Y와 대표 방향, 최대 기울기, 개인 기준, 표시 한계, 지속 시간 |
| 앞뒤 압력 | 앞쪽 또는 뒤쪽 상대 비중 80% 이상, 3초 이상, 새 프레임 8개 이상 | 발, 앞/뒤 방향, 최대 비중, 지속 시간 |

두 조건 모두 가속도 크기 1g ± 0.12g, 각속도 크기 12°/s 이하의 정지에 가까운 구간을 사용한다. 압력은 앞뒤 센서값의 상대 비중이며 체중 비중이나 임상적인 2D CoP가 아니다. 기울기는 발에 장착한 센서의 중력 대비 변화이며 실제 발목 상대 관절각이 아니다. X/Y 부호와 발목 안쪽·바깥쪽·발등·발바닥 사이의 장착 방향 보정은 아직 없다.

이 수치들은 앱의 관찰 조건이다. 개인 기준을 넘었다고 부상 위험도가 측정되거나 잘못된 걸음이 확인된 것은 아니다. 정지에 가까운 기록만으로 보행 중 자세·통증·근력·관절 손상·외력의 원인을 판단하지 않는다.

## 글은 어떻게 정하나

`qwen2.5:3b`를 이 PC의 Ollama에서 실행한다. 모델이 자유롭게 진단이나 운동 처방을 쓰지 않고, 서버가 제공한 후보에서 다음 두 항목을 선택한다.

1. **평소 걸을 때**: 발 기울기는 평평한 보행 환경 또는 발을 지지하는 편안한 신발에 대한 일반 안내 중 하나. 압력은 앞쪽/뒤쪽 기록에 맞는 안내를 서버가 지정하며, 반대쪽으로 억지로 체중을 옮기지 않고 편안한 속도로 걸으라는 내용이다.
2. **다음에 확인할 점**: 발 기울기는 센서 부착/기준 자세 확인, 압력은 해당 방향 센서/바닥/압력 재확인 중 하나.

서버와 화면에서 후보 및 항목 순서를 검증한다. 반대 압력 방향의 안내, 두 개의 점검 문구만 나오는 답, 알 수 없는 문구, 자유 텍스트는 거절한다. 모델 응답에 실패하면 오류를 표시하며 AI 답을 만들어내지 않는다.

화면의 **이 안내를 고른 기준**에 관찰 조건과 해석 범위를 표시한다. 관찰 수치는 코드가 계산하고, 화면에 나오는 문장 본문은 준비된 문구다. 같은 기록 ID는 캐시한 답을 다시 쓸 수 있다. 이때 수치와 생성 시각도 최초 요청 시점의 기록으로 묶어서 표시한다. 새 기록 ID가 생기면 새로 요청해야 한다.
