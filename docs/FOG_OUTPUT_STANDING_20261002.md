# FOG 팝업 · 레이저/진동 연동 및 서 있는 압력 기준

2026-10-02

## 변경

- 최신 적용된 ensemble AI 모델 및 배포 설정을 유지합니다.
- 실제 신선한 confirmed 판정으로 팝업이 열리면 `/api/ai/cue/sync`를 즉시 요청합니다. AI 상태 변경 시에도 출력 작업을 바로 깨웁니다.
- 서버는 최신 판정, 감지 중지, 자동 출력 중지, 보정/CSV 수집, 기기 식별자와 연결 상태를 다시 확인합니다. 테스트 팝업·오래된 화면만으로 출력을 강제로 켜지 않습니다.
- confirmed는 레이저 + 진동 70, warning은 진동 30이며 레이저는 끕니다. 양발에 각각 전달하고 400ms마다 갱신하며, 통신이 끊기면 보드의 1.5초 임대 시간이 만료됩니다.
- 4-2와 4-3 펌웨어에서 레이저를 DRV 인식 조건과 분리했습니다. 한 출력이 없어도 사용 가능한 출력은 동작하며 응답에 사용할 수 없는 출력을 구분합니다. 이 변경은 해당 보드에 새 스케치를 업로드해야 적용됩니다.
- 압력 표시는 첫 5초 서 있는 센서별 기준을 50점으로 저장한 고정 비례 환산입니다. 자세한 내용은 `PRESSURE_WALK_CALIBRATION.md`를 참고하세요.

## 서비스 반영 완료

사용자의 재시작 승인 후 2026-10-02 웹(8000/8001)과 AI(8787)를 재시작했습니다. 적용된 AI artifact는 위와 동일하며, 자동 출력은 켜짐으로 반영하고 사용자가 다시 켜둔 감지 설정을 유지했습니다. 새 `/api/ai/cue/sync` 경로도 응답을 확인했습니다.

이전 압력 최대값 보정은 새 정지 기준으로 전환하지 않고 `recalibration_required`로 표시합니다. 양발 BMI·압력 보정을 다시 진행하세요. 첫 5초에는 양발을 편히 딛고 서 있고, 다음 20초 동안 평소 걸음으로 보정합니다.
