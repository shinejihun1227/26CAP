# 2026-10-01 AI 배포 통합

사용자 제공 `StepOn_AI_only_20261001.zip`의 AI 파일을 적용했습니다. RF/CNN 가중치는 기존 파일과 SHA-256이 같으며, 이번 변경은 배포 설정과 판정·개인 보정·압력 보조 로직입니다.

## 적용 내용

- 기존 20Hz 입력, 4초 분석 창, 0.5초 간격 추론을 유지합니다.
- 기본 진입 기준은 기존 ensemble 설정을 사용합니다. 강한 신호는 기본 점수 0.40 이상인 분석 창 3개가 연속되고 기존 움직임 조건도 충족해야 합니다. 개인 보정으로 기준이 높아질 수 있습니다.
- 3초 준비 → 5초 정지 → 20초 보행으로 양발을 각각 다시 보정하면, 정지 압력 기준과 보행 점수 분포를 저장합니다. 기존 보정 파일은 계속 읽지만 새 압력/개인 임계값은 재보정 후 생깁니다.
- 압력 규칙은 모델 점수에 더하지 않고 최종 알림 상태를 보완합니다. 앞발 지속 하중, 보행 후 압력 흔들림, 짧은 걸음 간격, 제자리 하중 이동, 불규칙한 간격을 별도 근거로 표시합니다. 압력만 감지된 경우 AI 점수는 빈 값입니다.
- 양발에 같은 종합 알림을 보냅니다. `cue_level_supported: true`인 펌웨어는 주의 단계에서 약한 진동(level 30, laser false), 강한 신호에서 level 70과 laser true를 받습니다. 기존 펌웨어는 주의 출력을 건너뛰고 강한 신호의 기존 진동/레이저 명령만 받습니다. 이 압축파일에는 펌웨어가 없으며 보드 업로드는 하지 않았습니다.
- 제공 코드의 3회 발 구름 감지 시 5초 알림 억제를 적용했습니다. 하드웨어 감지 지원이 없으면 PC 가속도 기반 보조 검출을 사용합니다. 실제 착용 조건에서의 성능은 별도 확인이 필요합니다.
- Wi-Fi 입력 간격 허용은 제공 코드대로 5초입니다. 보간은 누락 구간의 실측 복원이 아니며 정확도 개선의 증거는 아닙니다. 최신 결과 유효 시간 2초와 최소 실제 수신 속도 8Hz 조건은 유지합니다.

## 기존 기능과의 병합

현재 코드의 감지 중지 저장/재개 API, ROM·COP 수신 콜백, 휴대폰 프록시 시간 제한 및 출처 검사를 보존했습니다. 감지 중지·보정·5초 억제 중 출력 차단, 오래된 압력 기록 폐기, 기기 교체 시 이전 압력 기준 해제, 백그라운드 보정 계산의 파일 교체 충돌 방지를 추가했습니다.

기존 파일 백업 위치는 `.codex-build/ai-update-20261001-backup-path.txt`, 제공 파일 해시는 `.codex-build/ai-update-20261001-incoming/manifest.json`에 기록되어 있습니다. UI 디자인, 기존 사용자 기록, Ollama 모델은 덮어쓰지 않았습니다.

## 검증 범위

Python AI 통합 테스트와 웹 테스트에서 실제 RF/CNN 가중치 추론, HTTP 연동, 개인 임계값, 압력 규칙, 감지 중지/재개, 출력 강도 전달, 알림 억제, 기존 ROM·COP 연결을 확인합니다. 테스트 센서 입력은 임시 합성 데이터이며 임상 정확도나 실제 착용 감지율 검증은 아닙니다.
