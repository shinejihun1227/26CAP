# FoG 경고와 감지 중지

실제 경고는 실기기 모드에서 사용합니다. PC 주소 예: `http://127.0.0.1:8000/?view=live&esp32=1&transport=sta&ai=1`. 휴대폰은 `127.0.0.1` 대신 같은 네트워크의 PC IP를 사용합니다. 시연 데이터와 CSV 재생은 경고를 발생시키지 않습니다.

- 화면 위쪽의 **소리·경고 테스트**(휴대폰: **소리 켜기 · 테스트**)를 한 번 누릅니다. 테스트라고 표시된 팝업, 짧은 알림음, 한국어 음성을 확인합니다. 브라우저마다 처음 사용자 클릭이 필요하며 소리 설정은 각 기기에서 켭니다.
- 실제 센서의 최신 AI 판정이 `confirmed`로 바뀌면 모든 주요 화면에서 **FoG가 발생하였습니다.** 팝업을 표시합니다. 소리를 켰다면 **보행동결, 포그가 발생하였습니다. 잠시 멈추고 안전을 확인해 주세요.**라고 안내합니다. 지속되는 같은 판정에는 반복하지 않으며, 다른 상태 이후 다시 감지되면 다시 알립니다.
- **감지 중지**는 이 PC의 AI 감지, 연결된 웹의 자동 팝업·음성, 자동 진동·레이저 출력을 함께 중지합니다. 휴대폰과 PC는 같은 서버 설정을 사용합니다. 마지막 하드웨어 명령은 최대 1.5초의 유효기간이 있고, 연결된 다른 웹은 다음 상태 조회에서 중지를 반영합니다.
- **감지 재개** 시 이전 판정과 분석 창을 지우고 새 데이터를 모읍니다. 중지 설정은 서버를 다시 시작해도 유지됩니다. 개인 보정·원시 데이터 수신·카메라 기능은 별도로 사용할 수 있습니다.
- PC 중지 요청이 실패하면 **이 화면 알림 중지 · PC 중지 미확인**으로 표시합니다. 이때 PC/네트워크 연결을 확인하고 **중지 다시 요청**을 누릅니다.

휴대폰에서는 웹을 전면에 열어 두고 미디어 음량을 확인합니다. 화면 잠금이나 백그라운드 상태의 음성 재생은 보장하지 않습니다. 한국어 목소리는 기기에 설치된 음성 중 선택되며, 음성 API가 없는 환경에서는 알림음만 사용합니다. 테스트 팝업은 센서나 기기에 출력 명령을 보내지 않습니다.

검증: `cap_web`에서 `node --test --test-concurrency=1 tests/*.test.mjs`; 저장소 루트에서 `.venv-ai\Scripts\python.exe -m unittest web.ai_bridge.tests.test_fog_cue web.ai_bridge.tests.test_integration`.
