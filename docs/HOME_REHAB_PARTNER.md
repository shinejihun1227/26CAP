# 홈재활 파트너 · MediaPipe 정면 보행

기존 MediaPipe 경로 `?view=mediapipe`를 유지합니다. 브라우저 화면에서 실행되며 서버 재시작은 필요 없습니다. 화면을 새로고침하면 새 모듈을 읽습니다.

## 사용 흐름

1. 카메라 동의 후 머리·어깨·골반·무릎·양발이 보이게 정면을 촬영합니다.
2. 편하게 선 자세를 **직접 인식한 2초** 동안 기록합니다. 잠깐 가려진 시간은 누적하지 않으며 최대 1.5초의 짧은 중단 동안 이미 모은 안정된 표본을 유지합니다. 자세가 달라지거나 오래 끊기면 다시 모읍니다.
3. 평소 의료진에게 안내받은 방식으로 **10초** 동안 편하게 걷습니다. 불편하거나 균형이 불안하면 중단합니다. 점선에 억지로 맞추도록 지시하지 않습니다.
4. 골반선·몸통·좌우 무릎–발목 선의 변화를 개별 확인합니다. 충분히 인식한 부위의 요약은 전체 인식이 부족해도 남습니다.

## 의미와 안내

- 골반선은 영상 평면에서 양쪽 골반의 높이 차이, 몸통은 어깨 중심–골반 중심의 기울기입니다.
- 발목 정렬은 무릎–발목 선의 화면상 기울기를 처음 자세와 비교한 값입니다. 발목 자체의 관절 ROM이나 안쪽/바깥쪽 손상 방향이 아닙니다.
- 하늘색 굵은 점선은 처음 자세의 방향입니다. 현재 몸 위치와 크기에 맞춰 표시하므로 걷는 경로를 고정하지 않습니다.
- 골반 5도, 몸통 8도, 다리선 12도 변화가 같은 부위·같은 방향으로 직접 인식에서 1초 이어질 때 확인 안내를 표시합니다. 표본이 끊기거나 방향이 바뀌면 연속 조건을 다시 모읍니다. 제품 안내용 상수이며 정상 보행, 낙상 위험 또는 치료 효과의 검증된 판정 기준이 아닙니다.
- 발목이 보이지 않으면 골반·몸통만 관찰할 수 있습니다. 해당 발목의 기준이나 현재 관절점이 없으면 그 부위의 수치를 만들지 않습니다.

## 끊김 처리

- 실시간 화면은 최근의 확실한 점을 최대 **400 ms** 동안 살구색 점선으로 유지합니다. 예측한 새 위치로 표시하지 않습니다. 유지한 점은 실측 계산에 전달하지 않습니다.
- 관찰 요약은 **양쪽 끝에 실측값이 있는 500 ms 이하 구간**만 시간에 비례해 선형 보간합니다. 각 부위마다 실측/보간/미확인을 따로 구분합니다.
- 여러 사람, 분석 지연, 큰 위치·크기·방향 변화, 급격한 각도 차이, 앞뒤 실측값이 없는 구간은 보간하지 않습니다. 여러 사람 또는 큰 위치·크기 변화가 감지되면 진행 중인 관찰을 중단하고 기준 재설정을 안내합니다. 이는 얼굴 신원 확인이 아닌 기하적 연속성 검사입니다.
- 전체 완료 조건은 직접 인식 **6초 이상**, 직접 인식 + 인정 보간 **7초 이상**입니다. 인정 보간은 최대 **2초**로 제한합니다. 실제 보간 총시간은 별도로 그대로 표시합니다.
- **기준 자세·최대 변화·변화 지속시간·실시간 주의 안내에 보간값을 쓰지 않습니다.**
- 부분 기록의 부위별 최대값은 그 부위를 직접 인식한 구간이 최소 1초일 때 표시합니다. 전체 관찰 완료와 같은 뜻이 아닙니다.

## 저장과 검증

새 형식은 `front-home-10s-v3`입니다. 이 브라우저의 기존 키 `stepon-front-observations-v1`에 최근 20건/30일을 유지하며 20초 구형 기록과 `front-10s-v2`도 읽습니다. 영상과 관절 좌표는 저장하지 않습니다. `metrics`에 부위별 실측 시간, 보간 시간, 실측 최대 변화와 가용 여부를 저장합니다.

- 단위 검사: `node --test tests/front-home.test.mjs tests/front-capture.test.mjs tests/front-observation.test.mjs tests/current-records.test.mjs`
- 합성 카메라: `/tests/fixtures/front-camera-check.html` (사용자 카메라/기록과 분리). 시작 → 기준 → 짧은 끊김 반복 → 완료, 왼발 미인식/오른발 변화, 모바일 393px 확인.
- 합성 입력 검증은 실제 환자에서의 인식 정확도나 치료 효과 검증을 대체하지 않습니다.

설계 참고: [MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker), [Parkinson's Foundation 물리치료 안내](https://www.parkinson.org/library/fact-sheets/physical-therapy). 임상 기준이나 검증된 보간 알고리즘을 이들 기관에서 제공받았다는 의미는 아닙니다.
