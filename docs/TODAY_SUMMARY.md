# 오늘 요약

일반·쉬운 화면·휴대폰의 `overview`는 동일한 세 영역을 사용합니다.

1. **FoG 점수표**: AI 브리지의 양발 `decision_score`와 백엔드가 선택한 종합 점수를 0–100점으로 표시합니다. 단순 평균·새 임계값을 만들지 않습니다. 2.5초 내의 유효한 분석만 표시하며 감지 중지·연결 끊김·개인 보정 미완료 시 점수를 숨깁니다. **AI 개인 보정**은 기기 설정의 개인 기준 패널을 펼쳐 이동합니다.
2. **BMI 기반 움직임 범위**: `/api/ankle-daily`의 오늘 기준을 사용합니다. **양발 범위 보정**, **왼발/오른발 기준 기록**으로 실제 준비 화면에 이동합니다. 이동만으로 측정을 시작하지 않습니다.
3. **앞뒤 압력 중심**: 두 센서 모델의 GPIO34(앞), GPIO35(뒤) 원본을 한 번씩 사용해 `앞 / (앞 + 뒤)`를 표시합니다. 부착 순서가 반대면 위치를 바로잡아야 합니다. 히트맵의 파생 표시나 임의 오차는 사용하지 않습니다. 4독립 센서는 가운데 두 측점을 절반씩 배분합니다. 작은 압력 합·오래된 값·잘못된 센서 계약은 표시하지 않습니다.

## 구 표시의 뜻

반지름은 개인이 기록한 기울기 95백분위 값, 점은 현재 중력 벡터의 기울기입니다. 파란 점은 기록 범위 안, 빨간 점은 기록 범위 밖입니다. 발끝 방향이 확인되지 않아도 **기존 3D 구체를 유지**합니다. 유효한 기울기가 있으면 구 중심으로부터의 거리를 기울기 크기로 사용해, 범위 안은 파란 점·범위 밖은 빨간 점으로 표시합니다. 방향 미확인 시 점은 고정된 대각선 위에서 거리만 변하며, 해부학적 방향을 뜻하지 않습니다. 이 경우 방향 화살표·앞뒤·안쪽/바깥쪽 방향 표시는 넣지 않습니다. 빈 범위나 움직이는 구간은 가짜 점으로 채우지 않고 이유를 안내합니다. 기록 범위 밖이라는 표시와 `기준 + 5°를 1초 이상 초과`하는 기존 이탈 기록 조건은 분리합니다.

ROM 피드백의 첫 문장은 숫자 나열 대신 **“왼발 안쪽이 들리는 꺾임을 조심하세요!”**처럼 방향 주의를 표시합니다. 여기서 방향은 관절 손상 방향이 아니라, 발끝 들기 보정으로 확인한 **발에서 들린 쪽**입니다. 안쪽·바깥쪽·발끝·뒤꿈치를 구분하고 왼발/오른발을 반영합니다. 최대 기울기·기록 기준·초과량·관찰 시간·센서 축은 접힌 ‘측정값·방향 근거 보기’에 남깁니다.

이탈 이벤트에 최대 기울기 당시의 `footDirection`과 해당 방향 보정 시각을 함께 저장합니다. 더 큰 기울기가 발생할 때만 방향도 갱신하며, 새 보정으로 과거 이벤트를 재해석하지 않습니다. 기존 X/Y 전용 기록, 방향 보정 실패, 90° 이상으로 방향이 모호한 기록은 **“왼발이 기록한 범위를 넘어 꺾이지 않도록 조심하세요.”**와 방향 재기록 버튼으로 안내합니다. Ollama에는 검증된 들림 방향과 해당 방향의 문구만 제공하며 반대 방향 문구는 응답 검증에서 거부합니다.

`기준 대비 기울기`는 처음 3초간 저장한 자세에서 발 센서의 중력 방향이 달라진 각도입니다. 위아래·좌우가 합쳐진 크기이며 다리 전체나 센서가 움직여도 변합니다. `기록 기준선`은 유효 기록값의 95백분위로, 방향별 관절 한계나 의학적 안전 범위가 아닙니다. 이전 `0–75.6°`와 같은 표기는 처음 자세 0°부터 기록 기준선 75.6°까지를 뜻했으며, 지금은 기준선을 별도 값으로 표시합니다. 발목의 정강이 대비 상대 각도와 수평 회전은 측정하지 않습니다.

구는 스칼라 최대 기울기를 모든 방향에 적용한 시각화입니다. 실제 3D 관절 운동 한계, 발 안/바깥 방향별 ROM, 부상 위험을 측정한 구가 아닙니다. 발 센서 하나로 정강이와의 상대 관절각이나 중력축 회전을 구할 수 없습니다. 센서 좌표계에서 중력 벡터 사이 최단 회전 벡터를 구해 점의 방향을 투영합니다. 깊이에 가려 범위 밖 점이 안으로 보이지 않도록 화면상의 거리를 조정하는 범위 게이지이며, 실제 발의 공간 위치가 아닙니다.

서버 폴링 결과는 2초가 지나면 현재 점을 숨깁니다. 화면 갱신은 기존 DOM을 보존하므로 폴링마다 카드와 보정 버튼을 통째로 다시 생성하지 않습니다. 구·점은 SVG이므로 WebGL이나 새 라이브러리 없이 PC와 휴대폰에서 표시합니다.

검증: `node --test tests/today-summary.test.mjs tests/ankle-daily.test.mjs tests/front-observation.test.mjs` (`cap_web` 폴더에서 실행).
