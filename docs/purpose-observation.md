# StepOn 준비·보행·움직임 관찰 (2026-10-01)

## 처음 화면과 세 가지 기능

처음 화면에서 **① 양발 보정 → ② 움직임 관찰 → ③ 오늘 기록 확인**을 안내합니다. 왼발·오른발 BMI 보정 버튼은 기존 AI 보정 API에 직접 연결되어 있습니다. 3초 준비, 5초 정지, 20초 평소 걸음 순으로 각 발을 보정합니다. 이 보정은 FoG 모델 입력을 준비하는 절차이며 아래 발 기울기 기준과는 별개입니다.

1. **AI 보행동결**: 기존 개인 보정과 20 Hz AI 모델, FoG 알림을 유지합니다. 쉬운 화면은 현재 신호, 소리 확인, 보정 이동, 자동 출력 중지만 표시합니다.
2. **발 움직임**: 카메라 없이 BMI270으로 양발의 기준 자세와 발 기울기를 기록하고, 서버가 받는 새 표본을 비교합니다.
3. **정면 보행**: MediaPipe로 한 사람을 정면 촬영합니다. 어깨·골반·무릎·발목을 인식하고 개인 기준 대비 골반선과 몸통의 영상상 기울기 변화를 관찰합니다. 기존 다른 관절 기록은 데이터 관리에 보존됩니다.

## 발 움직임 사용 순서

- 신발을 신고 앉아 왼발의 **3초 기준 맞추기**를 누르고 가만히 둡니다.
- **10초 방향·범위 기록**을 누릅니다. 처음 4초는 발끝을 몸쪽으로 살짝 들어 잠깐 유지하여 발끝 방향을 맞춥니다. 이후 6초는 편안한 범위에서 발끝을 천천히 위아래로 움직이고 양끝에서 잠깐 멈춥니다. 불편하면 중단합니다. 3초 기준 자세를 포함해 한 발당 총 13초입니다.
- 유효 표본이 충분하면 오늘 기준이 자동으로 저장됩니다. 오른발도 반복합니다.
- 기준 초과가 지속되면 시각, 발, 최대 기울기, 센서 X·Y 방향 변화가 오늘 이탈 기록에 남습니다. 이벤트를 열어 확인합니다.

측정값은 **기준 자세 대비 발 자체의 기울기 크기**이며 정강이와 발의 상대적인 발목 관절각(ROM)이 아닙니다. 일정한 센서 장착 회전은 기준 중력 벡터 비교로 상쇄하지만, 센서 편향이나 동적 가속도 오차를 교정하는 절차는 아닙니다. X·Y는 센서 좌표계이므로 실제 내번·외번、굽힘 방향이나 사람의 자세로 단정하지 않습니다. 화면의 화살표도 센서 축의 변화만 표현합니다.

가속도 크기 1g ±0.12g, 각속도 크기 12°/s 이하의 정지에 가까운 표본만 비교합니다. 3초 기준은 10개 이상·2.6초 이상·방향 편차 3° 이내, 10초 움직임 기록은 유효 센서값 15개 이상·첫/마지막 유효값 간격 6초 이상·95백분위 기울기 5° 이상·변화 3° 이상을 요구합니다. 2026-10-02에 움직임 기록의 최소 표본을 30개에서 15개로, 기록 시간을 15초에서 10초로 조정했으며 흔들림 제외 기준은 유지합니다. 개수는 움직인 횟수가 아닙니다. 화면에 유효값 수와 측정 구간을 표시하고, 연결 끊김·표본 부족·구간 부족·각도 변화 부족을 구분해 안내합니다. 양끝에서 잠깐 멈추면 안정적인 값을 받을 수 있습니다. 종료 시 마지막 센서값이 1초보다 오래되면 저장하지 않습니다. 95백분위 기울기 + 표시 여유 5°를 새 프레임 3개 이상·1초 이상 초과하면 이벤트를 기록합니다. 모두 실험용 품질/표시 조건이며 의료적 안전 한계가 아닙니다.

### 3D 구의 방향 표시

10초 기록의 처음 4초에 사용자가 발끝을 드는 동작으로 표시 기준을 맞춥니다. 중립 중력 벡터와 안정된 발끝 들림 벡터의 차이로 발끝 축을 만들고, 중립 법선과의 외적으로 착용자의 왼쪽 축을 만듭니다. 5–60° 구간에서 최소 8개의 서로 다른 값, 0.4초 이상의 안정된 구간, 방향 편차 3° 이내를 요구합니다. 샘플 간 0.5초 넘는 간격은 연결된 유지 동작으로 보지 않습니다. 장착 회전이 달라도 같은 동작은 같은 방향으로 표시되지만, 사용자가 처음에 다른 동작을 하면 기준도 잘못 맞춰질 수 있습니다.

구 위쪽 **전방(발끝)**은 발끝이 올라가는 방향, 아래쪽 **후방(뒤꿈치)**은 뒤꿈치가 올라가는 방향입니다. 측면의 안쪽·바깥쪽은 착용자 기준으로 양발에서 반대로 배치합니다. 화살표와 점은 **발에서 올라간 쪽**을 나타내며, 몸의 이동 방향·체중 중심 이동·발목 관절의 회전 방향을 뜻하지 않습니다. 양발 각각의 방향 이름도 함께 표시합니다.

방향 기준이 없거나 기울기가 90° 이상으로 방향이 모호해도 기존 3D 구체를 유지하고, 유효한 기울기는 구 안쪽 파란 점·구 바깥쪽 빨간 점으로 비교합니다. 이때 구 중심으로부터의 거리만 기울기 크기를 나타내며 점의 방향은 실제 발의 방향을 뜻하지 않습니다. 값이 오래됐거나 움직임이 커서 비교할 수 없으면 점을 숨기고 이유를 표시합니다. 기존 기준에 방향 정보가 없으면 구의 방향 표시를 위해 다시 기록해야 합니다. 재부팅·날짜 변경·기준 초기화 시 방향 기준도 해제합니다. 모든 방향에 같은 범위 반지름을 쓰며 방향별 가동범위나 해부학적 교정 정확도를 검증한 기능은 아닙니다. 과거 이벤트와 Ollama 안내는 기존 센서 X/Y 기록을 그대로 사용합니다.

PC 서버와 신발이 같은 네트워크에 연결되어 있으면 브라우저를 닫거나 다른 탭으로 이동해도 비교합니다. PC 종료/절전, Wi-Fi 단절, 큰 움직임 구간은 비교할 수 없습니다. **이탈 0회는 하루 종일 범위를 넘지 않았거나 안전했다는 뜻이 아닙니다.** 실제 비교한 시간과 기준 기록 이후 경과 시간을 나누어 보여줍니다. 하루 종일 실외 보행에서 연속 관절각을 감시하는 기능은 아직 구현/검증된 것이 아닙니다.

이벤트는 PC 프로젝트의 `.stepon-data/ankle-daily/events.json`에 최대 30일, 하루 200건까지 저장됩니다. 현재 화면은 오늘 이벤트를 표시합니다. 환경 변수 `STEPON_ANKLE_DATA_DIR`로 저장소를 지정할 수 있습니다. 기준은 서버 메모리에만 유지되며 서버 재시작, 날짜 변경, 기기/부팅 변경 시 다시 기록해야 합니다. 재착용하거나 사람이 바뀌면 반드시 기준을 초기화하세요. 현재는 연결된 한 착용자를 위한 공유 서버이며 웹 프로필별 기록 분리는 지원하지 않습니다.

## 정면 카메라 사용 순서

1. **정면 보행 → 카메라 사용 동의 → 카메라 켜기**. 다른 웹캠은 카메라 선택에서 고릅니다. 최초에는 권한을 허용한 뒤 기기 이름이 표시될 수 있습니다.
2. 카메라를 수평으로 두고 얼굴·양쪽 어깨·골반이 보이게 섭니다. 가능하면 무릎과 양발도 넣습니다. 초록 실선은 인식됨, 살구색 점선은 인식 불확실, 하늘색 선은 골반선입니다. 인식이 안 된 경우 인식 인원 수와 필요한 조정을 안내합니다.
3. **2초 기준 맞추기**로 잠시 정지합니다. **10초 관찰 시작** 후 정면을 유지하며 작은 걸음으로 움직입니다. 화면에서 남은 시간과 인식 시간을 확인하며, 10초 뒤 자동으로 끝납니다. 불편하면 중단합니다.

어깨·골반 네 점이 각도 계산의 필수 관절입니다. 얼굴과 두 어깨로 정면 여부를 확인합니다. 무릎·발목은 촬영 안내에 사용하며 잠깐 흐려져도 골반·몸통 계산을 차단하지 않습니다. 인식 신뢰도 기준은 유지합니다.
기준 자세는 안정된 인식 2초·5표본 이상을 모으며 최대 8초 안에 준비되지 않으면 원인을 표시합니다. 관찰은 10초 중 유효 인식 7초 이상일 때 완료됩니다. 중복·역순·오래된 프레임과 인식이 끊긴 구간은 유효 시간에 더하지 않습니다.
완료 후 골반선·몸통의 최대 변화각과 유효 시간·기준 변화 시간을 고정해 표시합니다. 다시 관찰하면 새 기록을 시작합니다. 기존 20초 기록은 유지하고 새 10초 기록과 관찰 길이를 구분합니다.

카메라 초기화와 센서/화면 갱신은 분리되어 동영상·캔버스를 주기적으로 갈아 끼우지 않습니다. 살구색 점도 화면에는 그리지만 각도 계산에 사용되는 점은 신뢰도 0.7 이상이어야 합니다. 두 사람이 보이거나 필수 점이 없으면 측정하지 않습니다. 800ms 이상 오래된 결과와 중복 결과를 유효 기록으로 세지 않습니다. 분석이 멈추면 재시작 안내를 보여줍니다.

골반선 변화 5° 또는 몸통 기울기 변화 8°가 개인 기준 대비 1초 이상 지속되면 ‘처음 자세와 차이가 보여요’를 표시합니다. 이는 임상 기준이 아니며 **골반 3차원 회전·구조적 틀어짐·잘못된 보행·질환을 판정하지 않습니다**. 정상 보행에서도 영상상 변화가 생길 수 있습니다. 카메라를 옮기면 기준을 다시 맞추세요.

정면 관찰 요약은 이 브라우저의 `stepon-front-observations-v1` localStorage에 최근 20건(30일 이내) 저장합니다. 영상·음성은 저장하지 않습니다. PC의 localhost 또는 HTTPS에서 카메라를 사용하세요. 일반 HTTP 휴대폰 주소에서는 브라우저가 카메라 접근을 막을 수 있습니다.

## 검증과 추가 개발 범위

자동 테스트에서 표본 누락, 중복 프레임, 움직임 제외, 지속 이탈, 재부팅/날짜 변경, 이벤트 복원, 정면 품질 기준 및 점선 그리기를 검증합니다. 별도 브라우저 검사 `cap_web/tests/mediapipe-runtime-check.html`은 실제 모델에 단색 영상 3개를 입력합니다. 이 검사는 사람 인식 정확도나 실착용 정확도를 입증하지 않습니다.

실제 발목 관절각·보행 중 꺾임 방향을 평가하려면 발과 정강이의 상대 방향 측정, 해부학적 축 보정, 시간 동기화 및 기준 계측기와의 검증이 필요합니다. 외출 중 연속 기록은 휴대폰/기기 저장과 연결 유지 설계를 추가해야 합니다.

근거: [MediaPipe Pose Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker), [IMU 기반 상대 관절각 측정 연구](https://pubmed.ncbi.nlm.nih.gov/24743160/). 이 자료는 본 앱의 정확도를 검증한 자료가 아닙니다.
