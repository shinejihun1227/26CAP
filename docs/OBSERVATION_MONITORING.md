# 보행 측정의 상태 관찰 화면

2026-09-24 추가. **보행 측정 → 상태 관찰**에서 `FoG 모니터링` 또는 `발 건강 모니터링`을 선택합니다. 기존 웹·AI 실행 방법과 ESP32 펌웨어는 그대로 사용합니다. 웹을 열어 둔 상태에서 바뀐 화면이 보이지 않으면 `Ctrl+F5`로 새로고침하세요.

## FoG 모니터링

- 현재 AI 상태, 관찰된 FoG 신호 구간 수, 총 관찰 지속시간, 가장 긴 구간을 보여줍니다.
- AI의 `confirmed` 상태가 이어지는 동안 한 구간으로 집계합니다. 양발 중 더 높은 최종 상태가 기준이며 양발 신호를 각각 더하지 않습니다.
- 그래프의 가로축은 시각, 세로축은 **초 단위의 관찰 지속시간**입니다. 막대에 마우스를 올리면 시각과 시간을 볼 수 있습니다.
- 최근 목록에서 신호 해제, 감지 중, 관찰 중단 여부를 구분합니다. 처음 연결했을 때 이미 감지 중이었다면 시작을 일부 관찰하지 못했다고 표시합니다.
- AI 분석 창의 타임스탬프를 사용합니다. 이는 모델 상태를 관찰한 시간으로, 실제 증상의 정확한 시작·종료 시간을 의미하지 않습니다.
- 연결 끊김, 보정 대기, 분석 결과가 2.5초 이상 오래됨, 일시정지, 브라우저 탭 숨김은 지속시간에 더하지 않습니다. 이후 다시 감지되면 별도 구간으로 표시합니다.
- `AI 판정 점수 · 진동·레이저 안내 설정`을 펼치면 기존 모델 상세 설명과 자동 출력 중지/재개 버튼을 사용할 수 있습니다. 이번 화면 변경은 물리 출력 제어 규칙을 바꾸지 않습니다.

## 발 건강 모니터링

`온도 / 습도 / 압력`을 누르면 양발 그래프와 현재 측정값을 바꿔 볼 수 있습니다.

| 지표 | 표시하는 값 | 해석할 때 확인할 점 |
|---|---|---|
| 온도 | 발마다 유효한 SHTC3 채널 평균, °C | 신발 안 센서 온도이며 피부 온도·체온으로 검증된 값이 아닙니다. |
| 습도 | 발마다 유효한 채널의 평균 상대습도, % | 양발 차이와 이전 값 대비 변화는 %p로 표시합니다. |
| 압력 | 한 발의 유효 압력 4채널 평균, 0–100 | 보정된 kg·kPa 값이 아니며 압력 분포는 해당 발 내 상대 비중입니다. |

- 온습도의 양발 차이는 **양쪽 모두 유효한 같은 위치의 센서**만 비교합니다. 위치가 겹치지 않거나 한 발이 끊기면 차이를 계산하지 않습니다.
- 최근 관찰 요약에는 선택 기간의 첫 유효값 대비 변화와 현재 압력 비중이 가장 큰 부위를 표시합니다. 정상·위험 임계값이나 당뇨발 진단 점수는 만들지 않습니다.
- 센서 채널 구성이 달라지거나 수신 공백·기기 재시작이 있으면 그래프 선을 연결하지 않습니다. 압력 0은 실제 0으로, 미수신은 `—`로 구분합니다.
- 같은 신발, 센서 위치, 활동 조건에서 비교하세요. 이 화면은 파킨슨병·당뇨발 환자의 상태 관찰을 돕는 참고 화면입니다.

## 관찰 범위와 저장

**최근 5분 / 15분 / 30분**을 선택할 수 있습니다. 자료는 이번 웹 접속의 메모리에 최대 30분만 유지되며 새로고침·창 종료 시 초기화됩니다. 다른 웹 메뉴로 이동해도 같은 탭이 활성 상태이면 관찰은 이어집니다. 탭을 숨긴 시간은 관찰하지 않습니다.

장기 비교는 `일별 기록 저장하기 → 데이터 관리 → 보행 기록`에서 측정 코드와 저장 동의를 확인한 후 `센서 기록 시작`을 사용하세요. 기존 저장소는 일별 통계입니다. **이 FoG 이벤트 목록과 30분 그래프를 영구 저장하는 기능은 아닙니다.** 기존 일별 AI 판정 표본 비율을 발생 횟수나 지속시간으로 변환하지 않습니다.

- `cap_web/src/components/observation-panel.js`: 탭, 그래프, 현재값, 관찰 요약.
- `cap_web/src/styles/observation-monitor.css`: PC·모바일 표시.
- `cap_web/tests/observation-monitor.test.mjs`: 연속 감지, 중복 응답, 중단, 범위 제한, 같은 위치 비교, 결측값과 실제 0, 그래프 단절 검증.

온도 판정 설계 참고: [IWGDF 예방 지침](https://iwgdfguidelines.org/prevention-guideline-2023/)의 온도 모니터링은 대응 부위의 **발 피부 온도**와 반복 관찰 조건에 관한 내용입니다. 따라서 이 장치의 신발 내부 온습도에 그 임계값을 그대로 적용하지 않았습니다.
