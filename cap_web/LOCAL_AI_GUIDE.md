# 로컬 발목 관찰·움직임 피드백 준비

관절 움직임 화면의 **이번 기록 요약**에서 로컬 AI 버튼을 쓸 때 적용합니다. 피드백은 `기록에서 보이는 점 → 이전 기록과 비교 → 오늘 해볼 수 있는 가벼운 움직임 → 다음 기록` 순서로 보여줍니다. 기록 숫자는 같은 조건의 관찰값으로만 설명하고, 각도에 맞춰 개인별 스트레칭 처방이나 목표를 만들지 않습니다. 별도로 표시되는 발목 위아래 움직임과 작은 원 그리기는 모든 사용자에게 공통으로 제시하는 선택형 일반 정보입니다.

1. Ollama를 공식 배포처에서 설치합니다: <https://ollama.com/download>
2. Windows 터미널이나 PowerShell에서 `ollama run qwen2.5:3b`를 실행합니다. 처음에는 모델 파일을 내려받을 수 있습니다. 실행 후 입력 프롬프트가 보이면 준비된 것입니다.
3. StepOn 웹 서버를 켜고, 품질 기준을 통과한 발목 기록을 저장한 다음 **발목 기록 해석 받기**를 누릅니다.

이 기능은 ChatGPT 앱을 호출하거나 OpenAI API를 사용하지 않습니다. 로컬 웹 서버가 같은 PC의 Ollama 서비스(`127.0.0.1:11434`)에 요약 요청을 전달합니다. 전달 데이터는 선택한 발목 이름, 중앙 각도, 움직인 범위, 유효 표본 비율, 같은 조건의 이전 기록과 범위 차이뿐입니다. 영상, 이름, 개인 코드, 원시 표본/CSV는 보내지 않습니다.

Ollama가 꺼져 있거나 모델이 준비되지 않으면 설치 및 실행 상태를 확인한 뒤 버튼을 다시 누릅니다. 모델 출력은 실험적 관찰 설명이며 진단, 정상/비정상 판정, 치료 목표 또는 운동 처방이 아닙니다. 움직임 중 통증·어지럼·불편감이 있으면 멈추고, 개인별 운동이 적절한지 궁금하면 의료 전문가에게 확인합니다. 2D 웹캠 각도는 임상 각도계와 같지 않습니다.
