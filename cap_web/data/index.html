CSV에 들어갈 항목과 단위

UTF-8 CSV, 첫 행은 열 이름, 이후 한 행은 한 시점의 원시 센서값입니다. 권장 64~100 Hz, 최소 32 Hz. 실제 장치 시각을 보존해 주세요.

표준 열값 / 단위
timestamp_ms장치 경과 시간, 밀리초, 엄격히 증가
raw_acc_x, raw_acc_y, raw_acc_z중력 포함 가속도, g
raw_gyro_x, raw_gyro_y, raw_gyro_z각속도, °/s
device_id, boot_id장치 식별자, 부팅 식별자
side, participant_id, session_id, placementleft/right, 참가자 코드, 회차, 부착 위치
label선택 메모: walking, turning, unlabeled 등

USB의 device_time_us는 ms로 변환하고, ax_g…gz_dps는 표준 6축 열로 자동 연결합니다. 참가자·회차가 없는 USB 파일에는 위 정보를 붙입니다.

빈 CSV 양식 다운로드 ↓

양식에는 가짜 센서값이 없습니다. 압력·온습도·카메라 값은 현재 IMU 모델 점수에 합산하지 않습니다.

3. CSV 연결과 분석

같은 참가자·회차·발·장치·부착 위치의 두 파일을 선택하세요. 보정 파일은 앞 25초를 사용합니다.

파일을 선택하면 형식·시간 간격·보정 동작을 검사할 수 있습니다.

CSV는 이 PC의 비공개 데이터 폴더에 저장됩니다. 이 분석용 보정은 실시간 화면의 개인 보정값을 바꾸지 않습니다. 새 데이터로 가중치를 재학습하는 기능은 포함하지 않습니다.

최근 기록과 분석

이 PC에 저장된 최근 20개 작업입니다. 보정·측정 기록을 다시 선택하거나 결과를 내려받을 수 있습니다.

점수는 해당 시간 구간의 모델 출력입니다. label은 수집자 메모이며 정답 판정이나 정확도로 사용하지 않습니다. 실제 보행동결 정답 구간이 있어야 성능 평가와 재학습을 별도로 진행할 수 있습니다.
