# 05 — I²C 주소·TCA 채널 검사

BMI270·TCA9548A·DRV2605L 및 TCA 뒤 SHTC3의 주소와 연결 경로를 확인하는 독립 스케치입니다. **측정/웹용 04번을 수정하지 않습니다.**

## 실행

1. USB·배터리 등 모든 전원을 분리하고 배선을 확인합니다. 센서 전원만 켜 놓고 ESP32를 다시 시작하지 말고, 검사 전 전체 모듈을 한 번 완전히 껐다 켜세요. 진동·레이저 출력부는 분리한 상태로 검사하는 것이 좋습니다.
2. SDA=GPIO6 / SCL=GPIO7 / 공통 GND, 모듈 정격에 맞는 전원을 사용합니다. 현재 3.3V 모듈에 5V를 넣지 마세요. BMI270 INT는 사용하지 않습니다.
3. Arduino IDE에서 `05_i2c_scan.ino`를 엽니다. ESP32C3 Dev Module, USB CDC On Boot Enabled로 해당 보드에 업로드합니다. **추가 라이브러리 없이 ESP32 코어의 Wire만 사용합니다.**
4. 시리얼 모니터를 **115200 baud**로 엽니다. 결과를 놓쳤다면 입력창에 **r**을 보내거나 RST를 한 번 누르세요. r은 검사만 반복하며 배선 변경은 반드시 전원을 끈 상태에서 합니다.
5. `[VISIBLE BEFORE ISOLATION]`부터 `[SUMMARY]` 또는 `[SKIP CHANNELS]`까지 결과를 복사해 공유합니다.
6. 진단 중에는 **Wi-Fi 접속과 웹 센서 수집이 중단**됩니다. 검사 후 `04_sta_bilateral/04_sta_bilateral.ino`를 왼발 0 / 오른발 1로 다시 업로드하면 복귀합니다. 양발은 각각 검사하세요.

2026-09-12 검증: Arduino ESP32 2.0.11 / ESP32C3 Dev Module / USB CDC Enabled에서 컴파일 성공. Flash 266,598 bytes(20%), global RAM 14,156 bytes(4%). 소스 계약 검사 6/6 통과. 실제 보드 업로드·실물 주소 스캔은 수행하지 않았습니다.

## 현재 04번에서 기대하는 결과

| 위치 | 주소 | 의미 |
|---|---|---|
| 직접 연결 | 0x68 | BMI270 기본 주소. CHIP_ID=0x24 여부도 확인 |
| 직접 연결 | 0x69 | BMI270 대체 주소일 수 있음. ID가 맞으면 현재 04의 0x68 설정과 불일치 |
| 직접 연결 | 0x71 | TCA9548A 설정 주소. ACK만으로 칩 종류는 확정할 수 없음 |
| 직접 연결 | 0x5A | DRV2605L 예상 주소. 모터 구동 정상 여부는 별도 |
| TCA CH3·4·5·6 | 각각 0x70 | SHTC3. 깨우기 후 ID와 CRC도 확인 |
| 압력센서/CD74HC4067 | 주소 없음 | 아날로그 방식이므로 이 검사에 나오지 않는 것이 정상 |

모든 주소는 **7비트 I²C 주소**입니다. 0x08~0x77만 스캔하고 예약 주소는 건너뜁니다.

## 출력 읽는 법

- `VISIBLE BEFORE ISOLATION`: 현재 보이는 모든 주소. TCA가 이전 상태로 켜져 있으면 하위 센서도 섞일 수 있어 곧바로 직접 연결로 단정하지 않습니다.
- `UPSTREAM / ALL TCA CHANNELS OFF`: 설정한 TCA의 채널을 모두 닫은 상태. 여기서 BMI270이 보이면 현재 코드처럼 직접 연결된 것입니다.
- `TCA ... / CHn`: 해당 채널만 연 뒤의 결과. `[shared upstream]`은 이미 직접 연결된 장치가 다시 보인 것이며 채널마다 추가 센서가 있다는 뜻이 아닙니다.
- `BMI270 ID MATCH`: 해당 주소의 CHIP_ID가 0x24입니다. 초기화·가속도 측정 정확성까지 검증한 것은 아닙니다.
- `SHTC3 ID+CRC MATCH`: 해당 채널의 SHTC3 식별 정보와 CRC가 일치합니다. 온습도 정확도 검증과는 다릅니다.
- SHT 채널 요약 `00011110`: 왼쪽부터 CH0~CH7, CH3·4·5·6 확인 성공. `0`은 미검증이며 물리적으로 없다는 확정이 아닙니다.
- `NO ADDRESS` 또는 버스 오류 다수: SDA/SCL 뒤바뀜, 전원·GND, 풀업, 접촉 불량, 통신선을 LOW로 붙잡는 모듈 등을 확인합니다. Idle logic HIGH는 정상 전압이나 풀업 저항이 있다는 보장이 아닙니다.

## TCA가 0x70 또는 다른 주소라면

안전을 위해 스캔에서 보인 임의의 0x70~0x77 장치를 자동으로 TCA라고 간주해 쓰기 명령을 보내지 않습니다. 채널 제어는 소스 상단 `TCA_SCAN_ADDRESS = 0x71`에만 수행합니다.

- 0x71이 없으면 주소 목록만 출력하고 채널 검사를 생략합니다.
- TCA만 연결한 상태에서 0x70이 나오면, 전원을 끄고 A0=3.3V / A1=A2=GND로 0x71을 맞춘 뒤 다시 검사하세요. SHTC3와 TCA 모두 0x70이면 주소 충돌이 발생합니다.
- 0x72~0x77이 실제 TCA임을 단독 검사로 확인했다면 `TCA_SCAN_ADDRESS`를 해당 주소로 바꿔 검사할 수 있지만, 현재 04는 0x71을 요구합니다.
- 상위 버스에 0x70이 이미 있으면 하위 SHTC3의 깨우기·ID 명령을 보내지 않고 경고합니다. 동일 주소 장치를 분리해야 채널별 판정이 가능합니다.
- 채널 선택/닫기가 실패하면 검사를 중단하고 나머지는 미검증으로 표시합니다. 전원을 완전히 껐다 켜고 문제 채널을 분리하세요.

TCA가 인식되지 않더라도 상위 버스의 0x68·0x69와 가능한 BMI270 ID는 검사합니다. 다른 I²C 모듈을 분리하고 BMI270만 직접 연결한 경우에도 사용할 수 있습니다. 센서 설정 레지스터 변경, BMI270 초기화, 진동 구동, Wi-Fi 설정 변경은 하지 않습니다. TCA 채널 변경 및 SHTC3 깨우기/ID 읽기/절전은 검사에 필요한 일시적 동작입니다.
