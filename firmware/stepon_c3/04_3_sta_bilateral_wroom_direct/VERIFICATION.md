# 4-3 검증 기록

2026-10-02 · FOG 출력 분리 및 서 있는 압력 50점 연동 반영

- Arduino ESP32 core 2.0.11, `esp32:esp32:esp32da`, 오른발 설정: 전체 컴파일 통과.
- 프로그램 859,273 bytes, 전역 RAM 46,104 bytes.
- 관련 웹 검사 79개 통과. Python 검사 54개 검증 완료(이전 최대값을 기대하던 테스트를 새 서 있는 기준에 맞춰 수정 후 재검증).
- 기존 4-2와 별도 압력 입력 구성입니다. 이번 FOG 수정은 4-2의 출력 코드에도 동일하게 적용했습니다.

실제 ESP32에는 새 펌웨어를 업로드하지 않았습니다. 기존 오른발 보드는 수동 테스트에서 레이저/진동 명령을 접수했지만 사용자는 두 출력 모두 실제로 나오지 않았다고 확인했습니다. 명령 응답은 실제 모터·발광 검증이 아닙니다. 배선과 구동 조건 확인이 필요합니다.

공유 ZIP에는 Wi-Fi 비밀번호와 펌웨어 바이너리가 없습니다. `README.md`에 핀맵과 업로드 순서를 정리했습니다. 이 버전의 레이저는 DRV 인식 여부와 별도로 제어되며 통신이 끊기면 기존 임대 시간이 만료됩니다.
