## 외부 무선 검색 결과

- Windows 내장 Intel Wi-Fi에서 새 스캔 요청을 실행했지만 진단 SSID가 검색되지 않았습니다.
- TP-Link USB Wi-Fi에서도 새 스캔 후 진단 SSID 및 위 AP MAC 주소가 검색되지 않았습니다.
- 두 스캔 요청의 Windows 반환 코드는 성공(0)이었습니다. 네트워크 연결이나 저장 프로필은 변경하지 않았습니다.
- AP 연결이 성립하지 않았으므로 DHCP, ping, HTTP 왕복 성공은 검증하지 못했습니다.
- 휴대폰에서도 검색되는지 사용자에게 확인을 요청했습니다. 이 기록 작성 시점에는 답변 대기 중입니다.

## 해석과 미확인 사항

1. 센서 처리 없이도 소프트웨어상 AP 시작 성공과 동작 상태는 확인되지만, 외부 무선 검색에서는 발견되지 않았습니다. 원래 센서 코드의 지연만으로 현재 증상을 설명하기는 어렵습니다.
2. 그렇다고 보드 고장이나 전원 불량이 확정된 것은 아닙니다. 실제 배선/부하가 물리적으로 제거된 것은 아니며, 전압·안테나·RF 출력은 측정하지 않았습니다.
3. 휴대폰의 근거리 검색으로 PC 수신 측과 보드 측 문제를 더 구분해야 합니다. 필요하면 전원을 모두 분리한 상태에서 외부 배선을 분리하고, 보드 단독 USB 전원으로 비교할 수 있습니다.
4. 이전 `03_final` 로그에서는 BMI270·DRV2605L은 인식되었지만 TCA9548A는 미인식, SHTC3는 0/4였습니다. 이는 별도 배선/주소/전원 점검 대상이며 이번 진단 코드는 센서를 검사하지 않습니다.
